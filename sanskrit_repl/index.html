Quick guide
Start writing
Use the workspace to write code, speak a draft, or open a ready-made template.

  

    
1. Choose a starting point
Write in the workspace or select one of the templates in the left pane. The English and Sanskrit versions of conversion examples are separate templates.

    
2. Edit or dictate
Use := for declarations and indentation for blocks. Browser dictation shows words live before placing them in the editor.

    
3. Run and inspect
Run code to see output below the editor. Each template starts with a fresh interpreter state so examples work one by one.
