# Sanskrit Interpreter examples

Run any file from the project root with `python3 -m sanskrit_interpreter examples/NAME.skt`. Open a `.skt` file in VS Code to try syntax colors, completions, hover help, and syntax diagnostics.

| File | What it shows |
| --- | --- |
| `demo.skt` | A tour of functions, loops, lists, and Go-inspired helpers |
| `conditionals.skt` | Variables, conditions, and formatted strings |
| `fibonacci.skt` | Functions, a while loop, and list building |
| `collections.skt` | Dictionaries, indexing, slices, sorting, and copying |
| `english_syntax.skt` | English keyword and built-in aliases |
| `spoken_commands.skt` | Explicit calculation and display commands |

For practical English-to-Sanskrit conversion pairs, see [conversion/README.md](conversion/README.md).
